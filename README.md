# Pruebas-software-calidad
Pruebas de software y aseguramiento de la calidad. Actividad desarrollada con casos de prueba manual y automática utilizando python y pytest.
Descripción del proyecto.
Tomando como ejemplo el caso planteado para este ejercicio, se realizaran pruebas manuales y automaticas, plasmando en ellas las tematicas vistas.
# Objetivos
Diseñar un plan de pruebas para las funcionalidades del sistema
identificar posibles errores por medio de las pruebas implementadas
implementar pruebas unitarias automatizadas por medio de las herramientas python y pytest
Documentar los resultados y observaciones obtenidas
# Herramientas utilizadas
GitHub: La cual será la herramienta en donde se almacenara y se gestionara el proyecto
Python: Sera el lenguaje de programación
pýtest: Herramienta escargada de las pruebas automatizadas
