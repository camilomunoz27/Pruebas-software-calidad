# Casos de prueba
# Sistema de gestión de tareas

Este documento contiene las pruebas diseñadas para comprobar las funcionalidades de las funciones claves del sistema.

## Módulos los cuales se evaluaran
1. Registro e inicio de sesión de usuarios.
2. Creación, edición y eliminación de tareas.
3. Asignación de tareas a usuarios.
4. Búsqueda y filtrado de tareas.
5. Consulta de tareas pendientes y completadas.
6. Administración del perfil de usuario.

## Tipos de pruebas que se utilizaran
**Pruebas Manuales:** Verifican el funcionamiento del sistema por medio de pruebas ejecutadas por una persona.
**Pruebas Automáticas:** Se desarrollan por medio de código en herramientas como pytest para comprobar de forma automática los resultados esperados.

## Registro de Resultados
Los resultados de cada una de las pruebas se documentara de la siguiente manera:

- Identificador de las pruebas.
- Funcionalidad evaluada.
- Datos de entrada.
- Resultado esperado.
- Resultado obtenido.
- Estado: aprobado o fallido.
